# Open Assistant WhatsApp Bridge

Simple bridge between **WhatsApp** and **Open Assistant**.

The bridge receives WhatsApp text messages and images, forwards them to Open Assistant and sends the response back to WhatsApp.

## Features

* WhatsApp text messages
* WhatsApp image support
* Forward messages to Open Assistant
* Send responses back to WhatsApp
* Webhook verification
* Self-hosted

## Installation

For installation, dependencies, configuration and running the bridge as a Linux service, see:

**[INSTALL.md](INSTALL.md)**

## How it works

```text
WhatsApp
   ↓
WhatsApp Business API
   ↓
Webhook
   ↓
Open Assistant WhatsApp Bridge
   ↓
Open Assistant
   ↓
WhatsApp
```
